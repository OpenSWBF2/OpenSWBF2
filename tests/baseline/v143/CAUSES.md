# v143 causes

Every v143 difference from `tests/baseline/vs2013/` and every later pinned change, one line each: `` `<table> <row>` | <cause> | <the cause> ``. A row key is the row's key columns joined by `/`, and `*` means every row of the table. A subject that is not a table row names what the cause pins. The detail of each cause is in the git history of this file. `tests/baseline/repin.ps1` copies a row only when a line here names its `<table> <key>`.
